Layout Components

Components for organizing and structuring forms.

Field Group

Group related fields together visually.

Usage

import { NgffFieldGroup } from 'ng-flex-form';

<ngff-field-group [title]="'Personal Information'">
  <ngff-input-text ... />
  <ngff-input-email ... />
</ngff-field-group>

Tabs

Organize form sections into tabs.

Usage

import { NgffTabs, NgffTabPanel } from 'ng-flex-form';

<ngff-tabs>
  <ngff-tab-panel [title]="'Basic Info'">
    <!-- Form fields -->
  </ngff-tab-panel>
  <ngff-tab-panel [title]="'Address'">
    <!-- Form fields -->
  </ngff-tab-panel>
</ngff-tabs>

Field Template

The base template wrapper used by all field components. Provides consistent structure with label, error display, and content projection.

Usage

import { NgffFieldTemplate } from 'ng-flex-form';

<ngff-field-template
  [field]="() => form.myField()"
  [params]="{ label: 'My Field' }"
>
  <!-- Custom input element -->
  <input type="text" ... />
</ngff-field-template>
