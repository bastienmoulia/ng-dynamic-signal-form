Field Types Reference

Complete reference of all available field types in the NgffFieldType enum.

NgffFieldType Enum

The NgffFieldType enum defines all available field types:

Enum Value Component HTML Input Type Description
InputText NgffInputText text Single-line text input
InputEmail NgffInputEmail email Email address input
InputPassword NgffInputPassword password Password input (masked)
InputSearch NgffInputSearch search Search input
InputTel NgffInputTel tel Telephone number input
InputUrl NgffInputUrl url URL input
InputNumber NgffInputNumber number Numeric input
InputRange NgffInputRange range Slider input
InputDate NgffInputDate date Date picker
InputTime NgffInputTime time Time picker
InputDatetimeLocal NgffInputDatetimeLocal datetime-local Date and time picker
InputMonth NgffInputMonth month Month and year picker
InputWeek NgffInputWeek week Week and year picker
InputCheckbox NgffInputCheckbox checkbox Checkbox input
InputRadio NgffInputRadio radio Radio button input
InputColor NgffInputColor color Color picker
InputFile NgffInputFile file File upload
InputHidden NgffInputHidden hidden Hidden input
Select NgffSelect - Dropdown selection
Textarea NgffTextarea - Multi-line text input

Usage with NgffFields

When using the NgffFields component, specify the field type in your params object:

import { NgffFieldType, NgffFormParams } from 'ng-dynamic-signal-form';

formParams: NgffFormParams = {
  username: {
    type: NgffFieldType.InputText,
    label: 'Username'
  },
  email: {
    type: NgffFieldType.InputEmail,
    label: 'Email'
  },
  birthdate: {
    type: NgffFieldType.InputDate,
    label: 'Birth Date'
  }
};

Direct Component Usage

You can also import and use components directly without NgffFields:

import { NgffInputText, NgffInputEmail } from 'ng-dynamic-signal-form';

@Component({
  imports: [NgffInputText, NgffInputEmail],
  template: `
    <ngff-input-text [field]="() => form.username()" />
    <ngff-input-email [field]="() => form.email()" />
  `
})
